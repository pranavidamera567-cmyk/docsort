# docsort

Automated document classification and search engine (Oct 2023 – Mar 2024).

Upload PDF, DOCX or TXT files. Text is extracted, cleaned, classified into configurable categories with TF-IDF features,
and stored with metadata in SQLite. Documents can be searched by keyword with relevance ranking, category filters and
classification-confidence indicators. An admin page lets you review predictions, correct them, retrain the model and export summaries.

**Stack:** Python, Flask, scikit-learn (TF-IDF), Pandas, SQLite, Jupyter Notebook, VS Code

## How it works
| Step | Module |
|---|---|
| Extract text (`pypdf`, `python-docx`) | `app/extract.py` |
| Preprocess: lowercase, strip digits/punctuation, drop stop words | `app/preprocess.py` |
| TF-IDF (1–2 grams) + logistic regression; probability = confidence (high ≥ 0.7, medium ≥ 0.4, else low) | `app/classifier.py` |
| Keyword search: documents must contain a query term, ranked by TF-IDF cosine similarity | `app/search.py` |
| Routes, SQLite storage, review and export | `app/__init__.py`, `app/db.py` |

**Categories** live in the database (defaults: invoice, resume, contract, research_paper, news_article) and can be added in the admin page.
The model bootstraps from `data/training.csv`, then learns from documents you approve or correct in the admin UI when you click *Retrain model*.
Retraining also re-classifies documents that are still pending review.

> `data/training.csv` is **synthetic** (generated by `scripts/make_training_data.py`), so the notebook's perfect cross-validation score
> says little about real-world accuracy. Review real uploads in the admin page and retrain to improve it.

## Run
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
flask --app wsgi run          # http://127.0.0.1:5000  (admin: /admin)
```
Set `ADMIN_PASSWORD` to protect the admin page, review, retrain, category-add and export endpoints with HTTP Basic auth (any username).
The search page and upload stay public. Without it, admin is open.

## API
| Method | Path | |
|---|---|---|
| POST | `/api/documents` | multipart field `file` (repeatable) → extract, classify, store |
| GET | `/api/documents?category=&status=` | list; `/api/documents/<id>` includes full text |
| GET | `/api/search?q=&category=&min_confidence=` | ranked results with score and snippet |
| POST | `/api/documents/<id>/review` | `{"category": "..."}` approve (same as prediction) or correct |
| GET/POST | `/api/categories` | list with counts / add |
| POST | `/api/model/retrain` | |
| GET | `/api/export/summary.csv`, `/api/export/documents.csv` | |
